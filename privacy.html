개인정보처리방침 (Privacy Policy)

시행일: 2026년 11월 18일

이 앱(유튜브 업로드 도구)은 채널 운영자 본인이 자신의 유튜브 채널에 직접 만든 영상을 올리기 위해 사용하는 개인용 프로그램입니다.

1. 사용하는 정보

Google 계정 로그인 시 YouTube Data API의 youtube.upload 권한만 요청하며, 이 권한은 운영자 본인 채널에 동영상을 업로드하는 데에만 사용합니다.

2. 저장 및 공유

  • 로그인 토큰은 운영자 본인의 컴퓨터에만 저장되며 외부 서버로 전송하지 않습니다.
  • 어떠한 개인정보도 수집·판매·제3자 제공하지 않습니다.
  • Google API에서 받은 정보는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 권한 철회

Google 계정 → 보안 → 타사 앱 액세스에서 언제든지 이 앱의 권한을 삭제할 수 있습니다.

4. 문의

문의는 채널 운영자에게 유튜브 채널을 통해 남겨 주세요.

This app is a personal tool used only by the channel owner to upload their own videos to their own YouTube channel. It requests only the youtube.upload scope, stores the login token only on the owner's computer, and does not collect, sell, or share any personal data.
